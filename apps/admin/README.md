# Fascino (Admin)

Premium admin dashboard for managing the Fascino – By Payal boutique.

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Supabase (Auth, Database, Edge Functions)

## Getting Started

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate to the project directory
cd <YOUR_PROJECT_NAME>

# Install dependencies
npm i

# Start the development server
npm run dev
```

## Deployment

Deploy via your hosting provider or CI/CD pipeline.
